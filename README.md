# 프로젝트 설명
서울 SeSAC 교육 과정에서 Kotlin의 이해를 위해 진행한 팀 프로젝트

- **주제** : 카페 주문 및 결제 시스템 구현
- **참여 인원** : 안드로이드 개발자 3명
- **역할** : 팀장
- **개발 기간** : 2025.05.23 ~ 2025.06.02
- **개발 언어** : Kotlin  
- **개발 환경** : IntelliJ
